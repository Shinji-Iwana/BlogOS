# BlogOS 画面の共通ルール

**バージョン:** 0.1.0
**最終更新日:** 2026-11-21
**主な変更:** 2026-11-21 全画面の見直しを始め、最初のルール（画面の上のリンクに「トップページに戻る」を出さない）を決めた（D-97-02）

---

# 1. 本書の目的と位置付け

本書は、BlogOS の画面（業務画面・確認画面・ポップアップ）の見た目と操作を揃えるための、共通のルールを定義する。

全画面の見直し（2026-11-21〜）で、画面ごとにばらばらだった部分を、利用者の指示に基づいて1つずつ決め、決めたものから本書に書き足す。決めた理由は `BLOGOS_DECISIONS.md` に記録する。

見直しが済んだら、画面ごとの画面設計書と画面遷移図を作り、BlogOS の上から見られるようにする（本書はその共通の部分になる）。

画面の種類（業務画面・API確認画面・DB確認画面）の定義は ARCHITECTURE 6-3 による。

---

# 2. 画面の上の部分

## 2-1. トップページへの戻り方

* 画面の上に「トップページに戻る」のリンクは出さない。トップページへは、全画面に共通のヘッダーの「BlogOS」から戻る（D-97-02）。
* 横から出る画面のパネル（`#screen-drawer`）で開いた画面は、パネルを閉じるとトップページに戻る。

---

# 3. 決まっていないこと（見直しの中で決める）

全画面の見直しの確認画面（`C:\Develop\blogos-ui-review\report.html`。Git の外）の「気づいた点」のうち、まだ決めていないもの。

* 画面の上のリンク（戻る先・関係する画面へのリンク）の書き方の残り
* 見出し（画面の名前）の形
* 説明の出し方
* 枠（パネル）の使い方
* ボタンの言葉と色
* 長い一覧のページ送り、表の列の幅とスマホでの扱い
* 画面に直接書いた見た目の指定の扱い
* 名前と中身が合わない画面
* ポップアップと画面のフォームの作りの違い
