# si-note：HTMLのルール

**si-note バージョン:** 1.0.0
**最終更新日:** 2026-09-24

**状態：未作成**（D-06-07）

本ファイルは、BlogOSのAI機能の「HTML出力」モードと記事の作成で使う、si-note用のHTMLのルール（HTMLテンプレート、コードの装飾、吹き出し、注意ボックス、比較表などの書き方）を定義する予定である。テーマ（Theme-SI-Originalから作るsi-note用のテーマ）のHTML構造・classが決まった時点で作成する。

作成までは、次の基本だけを適用する。

* 見出しタグ・リストタグ・tableタグを、意味に合わせて正しく使う。
* strongタグは強調する箇所だけに使う。装飾だけを目的としたHTMLを書かない。
* コードは `pre` タグと `code` タグで囲み、シンタックスハイライトに対応できる構造にする。
* 画像には必ず `alt` 属性を付ける。ファイル名は内容が分かる名前にする。
* 不要なHTML・class・styleを書かない。
