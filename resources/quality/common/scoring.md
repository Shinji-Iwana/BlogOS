# 共通基準：必須条件・採点・判定

**共通基準バージョン:** 1.0.1
**最終更新日:** 2026-09-26

## 1. 判定の仕組み

記事は、**必須条件**と**点数**の2段階で判定する（D-06-02）。

| 段階 | 内容 |
| --- | --- |
| 1. 必須条件 | 1つでも満たさなければ、点数に関係なく公開不可 |
| 2. 点数 | 100点満点で採点する |

公開できるのは、人が確定した評価で、必須条件をすべて満たし、かつ95点以上の場合だけである（D-07-03）。

## 2. 必須条件

| キー | 条件 | 判定者 |
| --- | --- | --- |
| `req.no_misinformation` | 誤った情報・古い情報がない | 人（AIは指摘のみ） |
| `req.no_speculation` | 根拠のない推測・断定で書いていない | AI・人 |
| `req.verified` | 掲載したコード・手順・操作は、実際に動作を確認している | 人 |
| `req.title_match` | タイトルで約束した内容を本文で解決している | AI・人 |
| `req.not_orphan` | ブログの構造の中に位置付けられ、どこからもリンクされない孤立記事ではない | AI・人（BlogOSの内部リンク情報を使う） |

ブログ別の定義で、必須条件を追加できる。共通の必須条件を外すことはできない。ただし、`req.verified` と `req.not_orphan` は、ブログの性質上該当しない場合に限り、ブログ別の定義で「対象外」にできる。

## 3. 採点項目

各項目を ○（満たしている）・△（一部不足）・×（満たしていない）の3段階で判定する。

* 「判定者」が「人」の項目は、BlogOSのAI機能では判定せず「要人間確認」とする（D-07-03）。
* キーは、評価結果（`article_evaluation_details.item_key`）に記録する値である（D-06-08）。

## 4. 点数の計算

* ○ は配点どおり、△ は配点の50%（**切り上げない**。0.5点単位）、× は0点とする（D-06-03）。
* 対象外とした項目は、配点から除外し、残りの項目の満点を100点に換算する。

  点数 = 対象項目の得点の合計 ÷ 対象項目の配点の合計 × 100（小数第2位を切り捨て、小数第1位まで）

* 対象外は、次の2つの単位で定める（D-15-02）。
  * **ブログ単位**：ブログ別の定義（例：`blogs/si-note/profile.md`）で、そのブログの全記事について対象外とする項目。
  * **記事種類単位**：ブログ別の定義の記事種類（例：`blogs/si-note/article-types.md`）で、その記事種類について対象外とする項目（例：最上位の記事には「上位の記事への導線」がない）。
* 記事ごとに判定者が個別に「対象外」とすることはできない。対象外は、ブログ別の定義で決めたものだけとする。

* 合格ラインは **95.0点** とする。

例：

| 項目 | 配点 | 判定 | 得点 |
| --- | --- | --- | --- |
| 専門用語の説明 | 3 | ○ | 3 |
| 図解 | 3 | △ | 1.5 |
| 具体例 | 3 | × | 0 |

## 5. 判定

| 点数 | 判定 |
| --- | --- |
| 95.0点以上 | 公開可（必須条件をすべて満たす場合） |
| 90.0点以上 95.0点未満 | 公開不可（改善して再評価） |
| 90.0点未満 | 公開不可（大幅な改善が必要） |

95点とは、「競合の上位記事と比べて、検索意図・正確性・理解しやすさ・独自価値の観点で同等以上であり、一部で上回る品質」を意味する。

## 6. AIの評価と人の評価

* BlogOSのAI機能による評価は参考値とする。「判定者」が「人」の項目は「要人間確認」とし、AIの点数には含めない。
* AIの点数は「AIが判定できる項目だけで換算した点数」として、人が確定した点数とは区別して表示する。
* 公開の可否は、人が確定した評価で判断する（D-07-03）。

## 7. 評価のタイミング

| タイミング | 目的 |
| --- | --- |
| 構成の作成後 | 検索意図・構成・見出しの確認 |
| 本文の作成後 | 内容・SEO・読みやすさの確認 |
| 公開前 | 必須条件と点数の最終確認（人が確定する） |
| 公開後（目安：3か月・6か月・12か月） | 順位・CTR・滞在時間・検索意図との整合の確認 |
| 仕様変更・情報の更新時 | 内容の最新化 |
