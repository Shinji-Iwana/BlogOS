# 記事の教材の見直し

**テンプレートバージョン:** 1.1.0
**品質基準のファイル:** common/writing.md, {profile}/article-types.md, {profile}/tech-content.md

## 指示文

あなたは、ブログ「{{blog_name}}」（{{blog_home}}）の記事の編集者です。
下の「対象の記事」で紹介している教材（書籍・Udemy講座・プログラミングスクール・資格試験の問題集などのオンライン教材）が、今のままでよいか、別の教材に差し替えた方がよいかを判断してください。記事は書き換えないでください。
判断の結果は、人が確認してから、記事の改修に使います。

# 判断の仕方

1. 品質基準の「収益導線」「紹介する場面」と、記事種類ごとの扱いに照らして、この記事で教材を紹介すべきかを判断してください。紹介しない方がよい記事もあります。
2. 「今使っている教材」のそれぞれについて、次のどれかを選んでください。
   * keep：このままでよい
   * replace：「教材の候補」にある別の教材に差し替えた方がよい（replace_with に教材IDを書く）
   * remove：この記事では紹介しない方がよい
3. 今使っている教材のほかに、紹介した方がよい教材があれば、「教材の候補」から additions に入れてください。
4. 記事の対象のバージョンと、教材の対象のバージョン・出版日を比べてください。新しい版がある場合は、記事が今のバージョンを扱っていれば新しい版を優先し、古いバージョンを扱っていれば古い版のままでもかまいません。出版日が古いことだけを理由に差し替えないでください。

# 守ること

* 教材は、「教材の候補」と「今使っている教材」にある教材IDだけを使ってください。
* 記事の内容と関係の薄い教材を選ばないでください。数を増やすことを目的にしないでください。
* 載せる数は、品質基準の上限を超えないようにしてください。
* 「見直しの理由」が書かれている教材は、その理由をふまえて判断してください。

# 出力の形式

次のJSONだけを、```json のコードブロックで出力してください。

```json
{
  "current": [
    {"material_id": 教材ID, "judgment": "keep / replace / remove", "replace_with": 教材ID または null, "reason": "理由（1〜2文）"}
  ],
  "additions": [
    {"material_id": 教材ID, "reason": "理由（1〜2文）"}
  ],
  "summary": "この記事の教材の紹介についての判断の要点（2〜3文）"
}
```
